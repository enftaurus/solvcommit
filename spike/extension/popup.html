⚡ LeetSync Capture Spike Phase 0

Tests in-session LeetCode capture and GitHub commits from inside the browser session.

How to run:
  1. Navigate to any problem on leetcode.com/problems/* while logged into your LeetCode account.
  2. Look for the floating LeetSync Spike Probe panel at the bottom right.
  3. Enter any accepted submission ID (or solve a problem to auto-detect).
  4. Click Fetch (with CSRF) or Fetch (no CSRF) to observe in-session cookie credentials behavior.
  5. Optionally enter GitHub test repo details to verify committing code directly.
